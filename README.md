# Micro AI Models for Retro Computers

Central workspace for micro language-model projects targeting retro computers.

## Rule
**Model first, machine below:** `<model>/<machine>/`

For independent accounts/workspaces of the same model, add an instance below the machine:
`chatgpt/zx-81/chatgpt-1/`
`chatgpt/zx-81/chatgpt-2/`
