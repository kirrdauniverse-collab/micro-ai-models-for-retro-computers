# CHATGPT1 — PICO ZX81 micro language model

This is the isolated ChatGPT working directory.

The directory contains an exact archive copy of the repository state that existed before this reorganization, plus ChatGPT's consolidated project index, error/repair log and breakpoint notes.

## Rules

- Future ChatGPT work goes here.
- Do not mix another model's active branch into this work tree.
- The complete test cassette must remain one .T81 file containing the sequential blocks required by the ZX81 workflow.
- Preserve every known-good regression before changing the next layer.
- Keep .P and .T81 artifacts together.
- Treat CI/build success and emulator/real-hardware success as separate facts.
