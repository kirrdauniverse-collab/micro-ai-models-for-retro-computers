# Pico AI v0.1 – First Design Release

**Date:** 2026-11-24  
**Status:** Design complete for Phase 1–2. First runnable BASIC loader ready. Full engine not yet implemented.  
**Goal of this version:** Establish architecture, memory map, UI rules, loader strategy, tokenizer concept, and initial vocabulary. Deliver a working BASIC loader that can be loaded in emulators.

## What is included

### Documentation
- `docs/02-screen-layout-and-ui.md` – Inverse headers, chat layout, status bar
- `docs/03-memory-map.md` – 16 KB allocation + RAMTOP protected area
- `docs/04-t81-structure-and-ramtop.md` – Multi-load strategy with BASIC loader + RAMTOP + NEW
- `docs/05-tokenizer-and-generation.md` – Bigram/trigram approach, special tokens, temperature
- `docs/06-basic-loader-v1.md` – Loader explanation
- This release notes file

### Source
- `src/loader-basic-v1.bas` – First BASIC loader (sets RAMTOP ≈ 30000, explains process, NEW)

### Knowledge
- `knowledge/vocab-v1.txt` – Initial English vocabulary (~200+ tokens) including special tokens, emoticons, common words, creator-related keywords

### Planned next (v0.2)
- Improved loader that also collects user name / date / gender into variables
- Persistent block structure (binary layout)
- Simple second block (machine code stub or larger BASIC demo)
- Tool to generate proper .P and multi-block .T81
- Expanded vocab + first bigram table

## How to test the current loader

1. Open the .bas file in a ZX81 emulator that accepts BASIC text, or convert it to .P
2. Or type it in manually (it is short)
3. RUN → read the screens → press ENTER → RAMTOP is set and NEW is executed
4. Then manually LOAD the next block (when we have one)

## Single .T81 requirement

All future releases will ship a single `.T81` file containing every block in order, so emulators (especially EightyOne) can load the whole tape image at once.  
Current v0.1 only has the first block as source; binary .T81 will appear from v0.2 onward.

## Versioning scheme
- v0.x = design + loader + tools
- v1.0 = first fully working chat + generation (even if limited)
- Later: knowledge packs as additional tracks in the same .T81
