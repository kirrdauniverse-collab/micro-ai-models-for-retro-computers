# Grok-1 – Nibble (ZX81)

**Modellpéldány:** grok / zx-81 / grok-1  
**Fejlesztő modell:** Grok (xAI)  
**Gép:** Sinclair ZX81 (16 KB)  
**Név:** Nibble

## Mi a Nibble?
Egy nagyon kicsi, BASIC-ben írt "okos" társ a ZX81-re.  
Hangulata van, tud egyszerű matekot, színeket kever, ideiglenesen tanul, és gondolkodik egy kicsit válaszolás előtt.
