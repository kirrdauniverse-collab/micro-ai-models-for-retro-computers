# Engine source (Z80)

Itt fogják lakni a valódi motor forrásai.

Tervezett fájlok:
- persist.asm   – persistent block kezelés
- tokenize.asm  – egyszerű tokenizer
- vocab.asm     – szótár
- generate.asm  – generáló mag
- screen.asm    – biztonságos kiírás (0x76 kerülése)

Az első működő gépi kódos rész a v0.4-ben jelenik meg.
